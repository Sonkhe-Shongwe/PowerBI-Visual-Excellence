# Design System Workspace

This folder will contain the reusable visual language developed from the research programme.

## Planned contents

- **themes/** — tested Power BI report theme JSON files.
- **colour-palettes/** — colour tokens, semantic palettes and contrast notes.
- **typography/** — font choices, scales and hierarchy rules.
- **reusable-components/** — documented KPI, header, filter, navigation and chart patterns.

## Current state

No production theme or reusable component has been approved yet. The initial principles are documented in [DESIGN_PRINCIPLES.md](DESIGN_PRINCIPLES.md).

A theme or component is promoted to reusable status only after:
1. Its source and purpose are documented.
2. It is tested in Power BI Desktop.
3. It is checked for readability and accessibility.
4. It is tested in more than one report context where practical.
5. Its dependencies and licence are recorded.
