# Visual Acceptance Criteria

**Purpose:** Establish a repeatable visual review process for reference studies and original reports.

## Comparison setup

Before comparing screenshots:
- Use the same report page dimensions and aspect ratio where possible.
- Use equivalent zoom and display scaling.
- Capture at a documented resolution.
- Keep the same filter state and data context.
- Record whether the reference is a screenshot, live report or local PBIX.
- Do not treat a different dataset or viewport as a direct pixel-equivalent comparison.

## Visual checklist

### Composition and hierarchy
- [ ] The page has a clear purpose.
- [ ] The most important insight is immediately identifiable.
- [ ] Visuals follow a deliberate grid and alignment system.
- [ ] Spacing is consistent.
- [ ] Density is appropriate for the audience.
- [ ] No important content is clipped or obscured.

### Typography
- [ ] Heading, body, KPI and label hierarchy is consistent.
- [ ] Text is readable at the target display size.
- [ ] Font weights and sizes are used deliberately.
- [ ] Labels and titles do not wrap awkwardly.
- [ ] Number formats and units are consistent.

### Colour and surfaces
- [ ] Colour palette is controlled and consistent.
- [ ] Semantic colours have stable meaning.
- [ ] Text and data marks have sufficient contrast.
- [ ] Borders, shadows and surfaces are consistent.
- [ ] Colour is not the only carrier of meaning.

### Charts and data
- [ ] Chart type matches the analytical question.
- [ ] Axes, units, scales and labels are correct.
- [ ] Sorting and legends are clear.
- [ ] Visual clutter is minimised.
- [ ] Important comparisons and context are visible.
- [ ] No chart design misrepresents the data.

### Components and interactions
- [ ] Cards, filters, buttons and tables share consistent styling.
- [ ] Selected and hover states are understandable.
- [ ] Tooltips are readable and useful.
- [ ] Navigation is visually discoverable.
- [ ] Reset and clear-filter behaviour is clear.

### Accessibility
- [ ] Contrast has been reviewed.
- [ ] Colour is not the sole indicator.
- [ ] Alternative text is meaningful where appropriate.
- [ ] Text size is appropriate.
- [ ] Reading order and keyboard behaviour have been considered.
