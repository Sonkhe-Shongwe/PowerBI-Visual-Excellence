# Reconstructions

This folder contains original Power BI implementations informed by the research references.

## Rules

- Use original or properly licensed data and assets.
- Link to the reference rather than copying its PBIX into this repository.
- State whether the work is a full-report reconstruction, page reconstruction or component study.
- Record the scope and known differences from the reference.
- Keep DAX, theme and custom component source with the reconstruction where appropriate.
- Capture before/after screenshots from our own implementation.
- Test all interactions before calling a reconstruction complete.

## Planned first reconstruction

[The World of Peaches](world-of-peaches/README.md) is the first proposed forensic study. The initial task is an audit, not an immediate rebuild.
