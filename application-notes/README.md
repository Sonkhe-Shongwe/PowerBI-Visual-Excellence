# Application Notes

This directory records how research findings may transfer into the user's own personal Power BI projects.

## Purpose

The user's personal projects are the actual implementation destinations. Their source code, PBIX files, data and project-specific deliverables remain in their own repositories.

This folder is only a lightweight bridge between research and application.

## What to record

For each potentially useful lesson:
- Reference study and source link.
- Pattern or technique identified.
- The problem it solves.
- The kind of personal project that may benefit.
- Adaptations needed for a different audience, dataset or business question.
- Risks, limitations and accessibility considerations.
- Whether the user wants to apply it.

Do not assume a pattern belongs in a personal project simply because it looks impressive. The user's project goals and analytical needs come first.

## Application rule

Before implementing a pattern:
1. Identify the target personal project with the user.
2. Confirm that the pattern solves a real need in that project.
3. Agree on the scope of the change.
4. Implement in the target project's own repository.
5. Record the learning and result here without duplicating project source files.
