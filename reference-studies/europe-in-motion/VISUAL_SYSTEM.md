# REF-007 — Visual System

**Source:** Landing-page screenshot, creator description and community feedback  
**Status:** Partial visual-system study; analytical-page screenshot/runtime review pending

## 1. Landing-page visual identity

The available screenshot shows:
- Dark blue top navigation.
- Light background.
- Circular illustration of European landmarks.
- Central World Champs EU Edition title.
- Navigation icons and social/author links.
- Clear Home, Overview, Between Regions, Contrasts and Head-to-Head labels.

This supports an assessment of the landing page only. It does not establish the full analytical-page palette or layout.

## 2. Dynamic visual styling

The creator says the report uses dynamic colours connected to the selected analytical context. A community commenter specifically praised the way colours are connected to the report elements.

The exact colour tokens, semantic mapping and contrast ratios are not available.

The design principle is to make the current analytical context visually coherent while keeping the underlying interaction familiar.

## 3. KPI cards and motion

The creator confirms:
- KPI cards on the Overview page use the HTML Content custom visual.
- Animated text overlays on KPI cards use HTML and CSS.

Community feedback describes the report as feeling like an interactive website. This is positive user feedback, but it does not establish whether motion is always helpful or accessible.

## 4. Map and analytical views

The community discussion praises the map implementation, visuals and tooltips. The page descriptions confirm:
- Regional map.
- Dynamic indicator cards.
- Trend and ranking charts.
- Configurable scatter plot.
- Head-to-head comparison.

The actual analytical-page screenshots were not available in the current study, so exact map styling, card layout, chart colours, typography and spacing remain unknown.

The creator's employer says the championship-winning solution incorporated a colour-blindness simulator.

This is a distinctive accessibility pattern worth investigating. The exact simulator interface and the extent to which it changes the report's colours are not known.

Other accessibility details remain unverified:
- Alt text.
- Keyboard navigation.
- Screen-reader order.

- Focus states.

## 7. Visual inspection checklist

When the live report or PBIX can be inspected, verify:
- How the dynamic colour system changes between indicators.
- Whether the colour-blindness simulator covers the full report.
- Whether the HTML KPI cards remain readable when animated.
- Whether the map legend and regional colours are clear.
- Whether the scatter plot uses labels and scales that explain the selected dimensions.
- Whether the head-to-head page gives both countries equal visual treatment.
- Whether motion can be paused or reduced.
