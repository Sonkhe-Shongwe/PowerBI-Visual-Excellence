# Reference Studies

This directory contains structured studies of external Power BI reports.

## Purpose

Understand how strong reports are structured, designed and engineered. Extract transferable principles and techniques that can inform the user's own projects.

These are case studies, not reconstruction assignments.

## Study standards

Each study should cover:
- Report purpose, audience and page architecture.
- Page sequence, layout, grid, hierarchy and visual density.
- Typography, colour, chart choices and component patterns.
- Navigation, filtering, bookmarks, tooltips and drillthrough.
- DAX, Power Query, theme JSON, TMDL, SVG, HTML/CSS or Deneb where inspectable.
- Strengths, weaknesses, trade-offs and unknowns.
- Transferable lessons and possible applications.

A study should distinguish direct observation from inference. Do not claim technical details that cannot be verified from the report or its source files.

## What we do not do

We do not recreate full external dashboards by default. If a small proof-of-concept is necessary to understand a technique, define the learning question first and keep the experiment narrowly scoped.
