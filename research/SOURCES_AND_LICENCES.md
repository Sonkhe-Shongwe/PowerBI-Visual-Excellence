# Sources, Attribution and Licensing

**Purpose:** Ensure that research and reconstruction are ethical, traceable and safe to publish.

This project studies public Power BI reports and may build original work inspired by techniques found in them. Public visibility does not mean unrestricted reuse.

## Non-negotiable rules

- Link to the original creator, report or official documentation.
- Record the date a source was checked.
- Inspect the repository's current licence before reusing code, themes, data or assets.
- Do not upload another creator's PBIX, screenshots, images, fonts, video, dataset or source files into this repository unless the applicable licence or explicit permission allows it.
- Do not remove copyright notices, attribution or licence text.
- Do not assume a repository-level licence covers embedded third-party material.
- Keep original implementations clearly distinguishable from reference material.
- If licence terms are unclear, link to the source and do not redistribute the material.

## What a licence review must cover

1. Repository-level licence.
2. Individual code files and component notices.
3. Third-party Power BI custom visuals and their terms.
4. Fonts, icons, illustrations, photography, video and other media.
5. Dataset licence, provenance and restrictions.
6. External APIs, CDNs and hosted assets.
7. Any restrictions on commercial use, modification, attribution or redistribution.

## Reuse categories

| Category | Treatment |
|---|---|
| MIT / permissive code | May be reusable subject to licence conditions and separate asset checks |
| Creative Commons | Follow the exact variant, attribution and other conditions |
| Proprietary / all rights reserved | Study and link; do not copy or redistribute without permission |
| Unknown / no licence found | Treat as not licensed for reuse |
| Official Microsoft sample | Follow the sample's published terms and the licence in the source repository |
| User-created original work | Document ownership and any third-party dependencies |

## Repository handling

- Store our own DAX, theme JSON, SVG, HTML/CSS and documentation.
- Store screenshots captured from our own implementations.
- Link to external PBIX downloads instead of mirroring them unless redistribution is explicitly permitted.
- Where a source licence permits code reuse, retain required notices and document modifications.
- Never commit credentials, tenant information, private datasets or personal information.

## Reference-specific notes

The initial repositories for The World of Peaches and City Sustainability Scorecard declare MIT licences. This is a useful starting point for code reuse, but the current LICENSE file and all bundled third-party materials must still be checked before copying any particular component or asset.

Microsoft's Power BI sample documentation also includes legal guidance stating that certain sample workbooks and related data are the property of obviEnce, LLC, and that use of those workbooks/data and visualisations requires the stated attribution and copyright notice. Treat each sample's own terms as authoritative; do not assume that a Microsoft-hosted download is automatically unrestricted for redistribution or portfolio publication.
